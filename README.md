# Проект «Клиника»

Веб-приложение для предварительной оценки простудных заболеваний по выбранным симптомам.

## Возможности

- интерактивный выбор симптомов;
- оценка длительности недомогания;
- предварительная категоризация возможного состояния;
- красный блок для опасных симптомов;
- история последних пяти оценок в локальном хранилище;
- адаптивный интерфейс для компьютеров и телефонов;
- без серверной базы данных и передачи персональных данных.

## Запуск локально

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

## Проверка сборки

```bash
npm run build
npm run preview
```

## Важное ограничение

Приложение является учебным прототипом и не ставит медицинских диагнозов. Алгоритм основан на фиксированных правилах и не заменяет консультацию врача.
